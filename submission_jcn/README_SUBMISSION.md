# Journal of Complex Networks submission package

Contents:

- `manuscript.tex` and `manuscript.pdf`: journal-formatted manuscript.
- `figures/`: the nine referenced figure assets, all in PDF format.
- `cover_letter.tex` and `cover_letter.pdf`: cover letter to the Editor-in-Chief.
- `supplementary_reproducibility_note.tex` and `.pdf`: validation and runtime summary.

Compile the manuscript from this directory with:

```sh
tectonic manuscript.tex
```

The manuscript uses standard `article.cls` and the packages `geometry`,
`amsmath`, `amssymb`, `graphicx`, `booktabs`, `array`, `float`, `hyperref`,
`xcolor`, `microtype`, and `caption`.

The archived code and data DOI is `10.5281/zenodo.21782190`. The package has
not been submitted through ScholarOne.
